## Your Assignment

Your assignment for this homework is to explore these two comics and vote on your favorite. I'll post the results of this very scientific experiment sometime before the end of the quarter. 

Go to both of these comic websites and explore them. Pick one from each site to include as part of your homework. Each choice should be from any month *except* May 2026. In this way, I can be reasonably sure that you actually explored the archives. 

Download these comics and insert them into the `homework_template.docx` file. Then, answer the third question in that document, which asks you to select which one you prefer.
